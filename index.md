Fedora Backup

Fedora Backup is a personal-use backup application that uses rclone and restic to securely store backup files in Google Drive.

The application runs on a privately managed Fedora Linux server and is not available as a public service.

How It Works

- Uses Google Drive authorization to access backup files.
- Uses the "drive.file" permission to access files created or opened through the application.
- Stores and retrieves encrypted backup repositories.
- Does not provide public access to the server or backup data.

Privacy

For information about how Google Drive data is accessed, used, and stored, please read the [Privacy Policy](https://shtab77.github.io/privacy.html).

This application is intended solely for personal backup and recovery purposes.
