Privacy Policy

Personal Fedora Backup Application

This is a personal-use application that uses rclone to store and retrieve encrypted backup repositories in Google Drive.

Data Access

The application uses the Google Drive "drive.file" permission to access files and folders created or accessed through the application.

Data Usage

Google Drive access is used exclusively for managing personal backup files, including uploading backups, retrieving backup data, listing backup files, and maintaining backup repositories.

Data Sharing

The application is not offered as a public service. It does not sell Google user data or share it with third parties for advertising or marketing.

Data Storage

Backup data is stored in the account owner's Google Drive. OAuth credentials are stored locally on the owner's private server.

Access Revocation

Google Drive access can be revoked through the Google Account's third-party connections settings.

Contact

For privacy inquiries, use the support email displayed on the application's Google OAuth consent screen.
